# Contributing

Contributions welcome. The bar for this codebase is the same one the model
holds itself to: show your work.

- **Bug fixes**: include a failing test first. The suite is self-contained;
  `swift test` must be green.
- **Model changes** (priors, transforms, likelihood): include the reasoning
  and, where possible, a synthetic-recovery result showing the change helps.
  Changes that improve fit on one fixture but break parameter recovery will
  not land.
- **New features**: open an issue first for anything larger than a fix.
- **Style**: match the surrounding code. Comments state constraints the code
  cannot show. No em dashes.

By contributing you agree your contributions are licensed under Apache-2.0.
